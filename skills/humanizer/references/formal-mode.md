# 격식 모드 : 강의자료, 제안서, 격식 글 전용

`SKILL.md`의 격식 게이트가 발동하면 이 문서의 규칙을 따른다. 대상 : 강의자료, 노션 교안, 제안서, 보고서, 격식 이메일(2문단 이상). 블로그, 후기, 에세이는 대상이 아니다(일반 모드).

이 모드는 [epoko77-ai/im-not-ai](https://github.com/epoko77-ai/im-not-ai)(Humanize KR)의 보수적 윤문 원칙 중 강의자료에 유용한 부분을 흡수해, 진백 격식 규칙과 결합한 것이다.

## 6대 원칙

1. **영혼 주입 OFF.** `SKILL.md`의 PERSONALITY AND SOUL 섹션(의견, 리듬 흔들기, 구어 1인칭, 사람 냄새)을 적용하지 않는다. 격식 글은 화자의 개성보다 내용의 정확성과 일관된 격식이 우선이다.
2. **친근체 → 격식 종결 (줄글=존댓말, 개괄식=개조식).** 구어와 반말 톤만 격식으로 올린다. **줄글(서술형 문단)은 존댓말(~습니다)**, **개괄식(불릿, 항목 나열, 요약, 표 셀, 슬라이드 정리)은 개조식**으로 맞춘다. 존댓말을 반말로 내리지 않는다. 한 문단(또는 한 불릿 묶음) 안에서는 종결을 섞지 않는다.
   - **개조식 세부** : ① 한자어 명사 종결을 우선(정함→결정, 만듦→제작), "-함/-됨/-음" 어미보다 명사로 끝내면 깔끔함 ② 목적격 조사 을/를 생략(결과물을 공유→결과물 공유) ③ 동사 나열은 '및'으로 연결(점검하고 보완→점검 및 보완), 가운뎃점(·)은 쓰지 않는다. ④ 글자를 기계적으로 줄이지 말고 문장이 전하려는 뜻을 명사형으로 정확히 옮긴다(튜터가 자리로 갑니다→기술 튜터 지원 예정, 2026-10-01). ⑤ 개조식이 아닌 평서문(제목, 한 줄 문장, 퀴즈 진술 포함)은 경어체(~습니다). 질문은 제목, 점검 항목, 본문 모두 문어체 "~는가"로 쓰고 "~습니까"는 쓰지 않는다(2026-10-01). 해요체(~요)와 반말 의문(~나, ~ㄹ까) 금지. 예외는 지시 예문, 직접 인용, 학습자 기입 예시.
3. **진백 격식 규칙 우선.** woka-writing-style 문체 규칙(`hooks/style-rules.md`. 플러그인은 세션 시작 시 주입하고, 바이브코딩 프로젝트는 CLAUDE.md가 불러온다)의 차단 동사와 감성과잉 목록이 본 스킬의 어떤 지시보다 위다. 충돌하면 무조건 격식 규칙을 따른다.
4. **과편집 상한.** 변경량이 원문의 30%를 넘으면 과편집을 경고하고, 50%를 넘으면 멈춘다. 격식 교정은 표현만 바꾸는 일이지 글을 새로 쓰는 일이 아니다.
5. **Do-NOT(보존 목록).** 코드, 명령어, 파일 경로, 영어 약어(LLM, MCP, API, GPU 등), 수치, 날짜, 고유명사, 제품명, 큰따옴표 직접 인용은 그대로 둔다.
6. **비유 추가 점검.** 다듬은 뒤 "원문에 없던 비유와 수사를 새로 넣지 않았나"를 한 번 더 확인하고, 넣었으면 되돌린다.

## 줄글 = 존댓말 / 개괄식 = 개조식 (예시)

| 글 형태 | 원문(친근, 구어) | 격식 종결 |
|---|---|---|
| 줄글 | Claude가 알아서 꺼내 써요 | Claude가 자동으로 불러옵니다 (존댓말) |
| 줄글 | ~하죠 / ~거든요 / ~잖아요 | ~합니다 / ~입니다 (존댓말) |
| 개괄식 | 14개 스킬을 한꺼번에 추가하는 꾸러미예요 | 14개 스킬을 일괄 추가하는 확장 묶음 (명사 종결) |
| 개괄식 | 무엇을 만들지 정함 / 고민해봐요 | 무엇을 만들지 결정 (명사 종결 우선) |
| 개괄식 | 완성한 결과물을 공유해요 | 완성한 결과물 공유 (조사 을/를 생략) |

> **시연 원문** : "플러그인이란 — `/plugin install superpowers` 한 줄로 위 14개 스킬을 ... 알아서 꺼내 씁니다."
> **줄글(존댓말)** : "플러그인은 `/plugin install superpowers` 한 줄로 위 14개 스킬을 Claude Code에 한 번에 더하는 확장 묶음입니다. 설치하면 Claude가 작업 상황에 맞는 스킬을 자동으로 불러옵니다."
> **개괄식(개조식)** : "플러그인 : `/plugin install superpowers` 한 줄로 14개 스킬을 일괄 추가하는 확장 묶음. 설치 시 작업 상황에 맞춰 자동 호출."

## 번역투 정밀 교정표 (Humanize KR 흡수)

`SKILL.md` 15번(번역투)을 세분화한 표. 강의자료에서 가장 흔한 AI 티다.

**판정 잣대(2026-08-23 사용자 확정)**: "이 문장을 팀장에게 말로 보고한다면 이렇게 말하는가." 말로 하면 어색한 문장이 번역체다. 조사 직역(①)만이 아니라 문장 뼈대(②)와 낱말 결합(③)까지 본다. 개조식(불릿·표 셀·카드)은 명사 종결이 불가피하므로 ②③을 느슨히 적용하고, 줄글은 전부 적용한다.

### ① 조사·연결어 직역

| 번역투 패턴 | 교정 |
|---|---|
| X에 대해(서) 논의/설명 | X를 논의/설명 |
| X를 통해/통하여 Y | X로 Y / X해서 Y / X함으로써 Y |
| X에 있어(서) | X에서 / X를 볼 때 |
| X와 관련하여 / 관련된 | X에 / X의 |
| X에 기반하여 / 바탕으로 | X로 / X를 근거로 |
| 경쟁력을 가지고 있다 (have+N 직역) | 경쟁력이 있다 / 경쟁력이 강하다 |
| 판단되어진다 (이중 피동) | 판단된다 |
| AI에 의해 생성된 | AI가 만든 |
| ~에서의 / ~으로의 / ~에의 (이중 조사) | 절·구로 풀어쓰기 |
| ~할 수 있다 남발 | (사실이면) ~한다 |

### ② 문장 뼈대 직역

| 번역투 패턴 | 교정 |
|---|---|
| 추상명사 주어 + 동사 ("소모가 쌓입니다", "불편이 존재합니다", "증가가 관찰된다", "변화가 발생한다") | 사람·사물 주어 + 동사, 또는 상태를 바로 서술 ("에너지가 소모됩니다/지칩니다", "불편합니다/불편이 생깁니다", "늘었다", "바뀐다") |
| 존재하다 (there is 직역: "문제가 존재한다") | 있다 ("문제가 있다") |
| 이루어지다·진행되다 (행위자 숨김: "회의가 이루어졌다") | 행위자 주어 + 능동 ("회의를 했다") |
| ~하는 것이 가능하다/필요하다/중요하다/요구된다 (가주어) | ~할 수 있다 / ~해야 한다 / ~이 중요하다 |
| ~하는 것을 돕는다 (help to) | ~하는 데 도움이 된다 / ~하기 쉽게 한다 |
| ~로 하여금 ~하게 하다 | ~가 ~하게 하다 |
| 가장 ~한 것 중 하나 | 손꼽히는 / 대표적인 |
| ~라고 불리는 / ~로 알려진 | ~라는 / (삭제) |
| ~에 위치하다 / ~을 포함하다 남발 | ~에 있다 / ~도 있다·~까지 |
| ~들 복수 남발 ("많은 사람들이") | 단수형 ("많은 사람이") |
| 그/그녀/그것/이것은 대명사 남발 | 명사 반복 또는 생략 |
| 관형절 겹침 ("AI가 만들어내는 변화가 가져오는 영향이 미치는 범위") | 문장을 끊어 한 문장에 한 생각 |
| 보다 나은 / ~에 다름 아니다 / ~하지 않으면 안 된다 / ~을 요한다 (일본어투) | 더 나은 / 바로 ~이다 / ~해야 한다 / ~이 필요하다 |
| 의문사를 따옴표로 명사화 ("'무엇'을 찾다", "'왜'가 중요하다", "우리 조가 고른 '무엇'") — the what / the why 직역 | 절로 풀기 ("무엇을 자동화할지를 정한다", "왜 하는지가 중요하다", "조가 고른 문제 하나") |
| 서술어를 뗀 슬로건식 대구 ("해결은 AI가, 정의는 사람이", "속도는 도구가, 방향은 사람이") — 광고 카피 직역 | 서술어를 살린 평서문 ("어떤 문제를 해결할지는 사람이 정하고, 해결하는 일은 AI가 맡는다"). 슬로건이 필요해도 본문·헤드라인에는 평서문으로 두고 구두로만 쓴다 |
| 서술어를 생략하고 부사나 명사로 끝낸 안내문 ("한 줄부터 다시", "결과 확인 후 다음 요청으로") | 서술어까지 쓴다 ("한 줄부터 다시 고민해 보세요"). 화면 안내문도 문장으로 끝맺는다 |
| 화자가 지금부터 할 행동을 현재형으로 예고 ("먼저 파일을 봅니다", "이 장에서는 설정을 살펴봅니다", "직접 등록해 봅니다", "완성 문안까지 씁니다") (영어 "I look at", "Let's try" 직역) | "~겠습니다"로 예고 ("확인하겠습니다", "살펴보겠습니다", "등록해 보겠습니다", "작성하겠습니다"). 화자의 다음 행동과 학습자와 함께 진행하는 실습 안내 모두 해당. 동사는 차단 2대로 바꾸고 어미만 "~겠습니다". 사실과 기능 설명("누르면 저장됩니다")은 현재형 유지(2026-10-20 사용자 확정) |
| 개조식 라벨(카드 제목, 바로 가기 칸, 표 머리)에 부사가 남은 명사구 ("스킬 다시 시험", "한 번 더 확인"). test again 같은 영어 동사구를 낱말 순서대로 줄인 모양이다. 부사는 용언을 꾸미는 말이라 명사 앞에 두면 서술어가 빠진 채로 읽힌다 | 안내문 처방(서술어나 "-하기" 붙이기)을 라벨에 옮기지 않는다. 부사는 빼고, 그 장이 실제로 하는 일을 한자어나 정착 외래어 명사로 이름 붙여 '및'으로 잇는다 ("스킬 테스트 및 검증"). "다시", "한 번 더"처럼 순서만 알려 주는 말은 내용이 아니므로 버린다. 다의어 명사는 맥락에서 한 뜻으로만 읽히는 정착어로 바꾼다("시험"은 exam이나 차량 시험으로도 읽힘 → "테스트") |
| 정보를 긴 관형절에 싣고 속이 빈 동사(두다·하다·가지다·있다)로 끝맺기 ("떨어져서 다르게 보는 담당자를 둡니다", "~하는 체계를 가진다") — we have/put a N who… 직역. 표식 낱말이 없어 목록 대조로는 안 잡히고 "말로 보고하면 이렇게 말하는가"를 실제로 해 봐야 드러난다 | 동작 동사가 문장을 끌게 ("관여하지 않은 제3자가 봐야 제대로 보입니다"). 카드·그림 글처럼 짧게 써야 할 때 특히 생기므로, 줄일 때는 관형절을 늘리지 말고 주어를 빼고 동작 동사를 바로 쓴다 |
| 셈 단위 군더더기 : 결정 하나를, 숫자 하나 고르기, 예상 한 줄 적기, 결정이 하나 있다 (영어 a/one 직역, 구체성을 더한다는 착각) | 수량이 요점이 아니면 수사를 빼고 조사로 잇는다 : 결정을, 숫자 고르기, 예상 적기, 결정이 있다. 세는 것이 지시의 핵심일 때만 둔다(2026-10-18) |

### ③ 낱말 결합(연어) 위반·영어 추상명사 직역

| 번역투 패턴 | 교정 |
|---|---|
| 한국어에서 서로 붙지 않는 명사+동사 (소모가 쌓이다 · 효율이 발생하다 · 영향을 가하다 · 결과를 생산하다 · 문제를 경험하다) | 굳어진 사무실 연어 (피로가 쌓이다 · 효율이 오르다 · 영향을 주다 · 결과를 내다 · 문제를 겪다/어렵다) |
| ~의 측면에서 / ~의 차원에서 / ~의 영역에서 / ~의 형태로 (in terms of / in the form of) | 문장으로 풀거나 삭제 ("비용 측면에서 유리하다"→"비용이 적게 든다") |
| 접근·관점·요소·프로세스 같은 영어 추상명사 직역 어휘 남발 | 구체 명사 또는 동사로 ("새로운 접근이 필요하다"→"방법을 바꿔야 한다") |
| 기본적으로·일반적으로·결과적으로·본질적으로 (basically/generally/essentially 직역 부사) | 삭제 또는 구체 조건으로 |
| ~라고 생각됩니다 / ~로 보여집니다 (피동 판단) | ~라고 봅니다 / ~로 보입니다 |
| 영어 동사 직역 : answer → 답하다, look at·see → 보다 ("질문 1은 지금부터 답합니다", "방법을 봅니다") | 강의 맥락의 동사로 : 고민하다, 배우다, 살펴보다 ("고민해 보겠습니다", "방법론을 배워 볼게요") |

## 격식 모드 자체검증 (다듬은 뒤 점검)

1. 수치, 고유명사, 명령어, 인용 100% 보존됐나
2. 변경률 30% 이하인가 (50% 초과 시 중단)
3. 줄글은 존댓말(~습니다), 개괄식(불릿, 항목, 요약)은 개조식(-함/-임/-됨)으로 맞췄나
4. 진백 차단 동사(박다, 굴리다, 꺼내 쓰다, 손대다 등)와 감성과잉이 0건인가
5. 원문에 없던 비유, 수사를 새로 넣지 않았나
6. 번역투(위 ①②③ 표) 잔여가 없는가, 잣대 : 팀장에게 말로 보고한다면 이렇게 말하는가

한 항목이라도 위반이면 해당 부분만 되돌려 다시 다듬는다.
