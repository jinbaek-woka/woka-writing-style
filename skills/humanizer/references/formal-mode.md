# 격식 모드 — 강의자료·제안서·격식 글 전용

`SKILL.md`의 격식 게이트가 발동하면 이 문서의 규칙을 따른다. 대상: 강의자료, 노션 교안, 제안서, 보고서, 격식 이메일(2문단 이상). 블로그·후기·에세이는 대상이 아니다(일반 모드).

이 모드는 [epoko77-ai/im-not-ai](https://github.com/epoko77-ai/im-not-ai)(Humanize KR)의 보수적 윤문 원칙 중 강의자료에 유용한 부분을 흡수해, woka-style 문체 규칙과 결합한 것이다.

## 6대 원칙

1. **영혼 주입 OFF.** `SKILL.md`의 PERSONALITY AND SOUL 섹션(의견·리듬 흔들기·구어 1인칭·사람 냄새)을 적용하지 않는다. 격식 글은 화자의 개성보다 내용의 정확성과 일관된 격식이 우선이다.
2. **친근체 → 격식 종결 (줄글=존댓말, 개괄식=개조식).** 구어·반말 톤만 격식으로 올린다. **줄글(서술형 문단)은 존댓말(~습니다)**, **개괄식(불릿·항목 나열·요약·표 셀·슬라이드 정리)은 개조식**으로 맞춘다. 존댓말을 반말로 내리지 않는다. 한 문단(또는 한 불릿 묶음) 안에서는 종결을 섞지 않는다.
   - **개조식 세부:** ① 한자어 명사 종결을 우선(정함→결정, 만듦→제작) — "-함/-됨/-음" 어미보다 명사로 끝내면 깔끔함 ② 목적격 조사 을/를 생략(결과물을 공유→결과물 공유) ③ 동사 나열은 '및'으로 연결(점검하고 보완→점검 및 보완) — 가운뎃점(·)은 쓰지 않는다.
3. **woka-style 문체 규칙 우선.** woka-style 플러그인의 문체 규칙(세션 시작 시 주입되는 `style-rules.md` — 차단 동사·감성과잉 목록)이 본 스킬의 어떤 지시보다 위다. 충돌하면 무조건 문체 규칙을 따른다.
4. **과편집 상한.** 변경량이 원문의 30%를 넘으면 과편집을 경고하고, 50%를 넘으면 멈춘다. 격식 교정은 표현만 바꾸는 일이지 글을 새로 쓰는 일이 아니다.
5. **Do-NOT(보존 목록).** 코드·명령어·파일 경로·영어 약어(LLM·MCP·API·GPU 등)·수치·날짜·고유명사·제품명·큰따옴표 직접 인용은 그대로 둔다.
6. **비유 추가 점검.** 다듬은 뒤 "원문에 없던 비유·수사를 새로 넣지 않았나"를 한 번 더 확인하고, 넣었으면 되돌린다.

## 줄글 = 존댓말 / 개괄식 = 개조식 (예시)

| 글 형태 | 원문(친근·구어) | 격식 종결 |
|---|---|---|
| 줄글 | Claude가 알아서 꺼내 써요 | Claude가 자동으로 불러옵니다 (존댓말) |
| 줄글 | ~하죠 / ~거든요 / ~잖아요 | ~합니다 / ~입니다 (존댓말) |
| 개괄식 | 14개 스킬을 한꺼번에 추가하는 꾸러미예요 | 14개 스킬을 일괄 추가하는 확장 묶음 (명사 종결) |
| 개괄식 | 무엇을 만들지 정함 / 고민해봐요 | 무엇을 만들지 결정 (명사 종결 우선) |
| 개괄식 | 완성한 결과물을 공유해요 | 완성한 결과물 공유 (조사 을/를 생략) |

> **시연 원문:** "플러그인이란 — `/plugin install superpowers` 한 줄로 위 14개 스킬을 ... 알아서 꺼내 씁니다."
> **줄글(존댓말):** "플러그인은 `/plugin install superpowers` 한 줄로 위 14개 스킬을 Claude Code에 한 번에 더하는 확장 묶음입니다. 설치하면 Claude가 작업 상황에 맞는 스킬을 자동으로 불러옵니다."
> **개괄식(개조식):** "플러그인: `/plugin install superpowers` 한 줄로 14개 스킬을 일괄 추가하는 확장 묶음. 설치 시 작업 상황에 맞춰 자동 호출."

## 번역투 정밀 교정표 (Humanize KR 흡수)

`SKILL.md` 15번(번역투)을 세분화한 표. 강의자료에서 가장 흔한 AI 티다.

| 번역투 패턴 | 교정 |
|---|---|
| X에 대해(서) 논의/설명 | X를 논의/설명 |
| X를 통해/통하여 Y | X로 Y / X해서 Y / X함으로써 Y |
| X에 있어(서) | X에서 / X를 볼 때 |
| X와 관련하여 / 관련된 | X에 / X의 |
| X에 기반하여 / 바탕으로 | X로 / X를 근거로 |
| 경쟁력을 가지고 있다 (have+N 직역) | 경쟁력이 있다 / 경쟁력이 강하다 |
| 판단되어진다 (이중 피동) | 판단된다 |
| AI에 의해 생성된 | AI가 만든 |
| ~에서의 / ~으로의 / ~에의 (이중 조사) | 절·구로 풀어쓰기 |
| ~할 수 있다 남발 | (사실이면) ~한다 |

## 격식 모드 자체검증 (다듬은 뒤 점검)

1. 수치·고유명사·명령어·인용 100% 보존됐나
2. 변경률 30% 이하인가 (50% 초과 시 중단)
3. 줄글은 존댓말(~습니다), 개괄식(불릿·항목·요약)은 개조식(-함/-임/-됨)으로 맞췄나
4. 차단 동사(박다·굴리다·꺼내 쓰다·손대다 등)·감성과잉이 0건인가
5. 원문에 없던 비유·수사를 새로 넣지 않았나
6. 번역투(위 표) 잔여가 없는가

한 항목이라도 위반이면 해당 부분만 되돌려 다시 다듬는다.
