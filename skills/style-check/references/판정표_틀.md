# 판정표 틀과 명령 모음

## 명령 예

`<이 스킬 폴더>`는 이 스킬의 `SKILL.md`가 있는 폴더입니다. `<작업 폴더>`는 점검표를 둘 폴더이며 플러그인 폴더 밖이어야 합니다.

```
# 1. 점검표 만들기(그림 글자를 검토하면 --figure 추가)
python3 <이 스킬 폴더>/scripts/build_checklist.py --out <작업 폴더>

# 2. 낱말 후보 찾기(파일은 여러 개 가능)
python3 <이 스킬 폴더>/scripts/lint_style.py <검사할 파일> --out <작업 폴더>

# 3. 판정표 누락 검사(점검표를 --figure로 만들었으면 같이 추가)
python3 <이 스킬 폴더>/scripts/check_coverage.py <판정표 md> --out <작업 폴더>
```

공통 인자는 다음과 같습니다.

| 인자 | 뜻 | 기본값 |
|---|---|---|
| --out | 점검표를 두는 폴더 | 현재 폴더 |
| --rules-root | 플러그인 뿌리(hooks/style-rules.md가 있는 폴더) | 스크립트 위쪽에서 자동 탐색 |
| --formal | 격식 모드 formal-mode.md 경로 | 뿌리 안 skills/humanizer/references |
| --project | CLAUDE.md가 있는 프로젝트 폴더 | 현재 폴더 위쪽에서 자동 탐색 |
| --figure | 그림 규격(LG 번호) 포함 | 미포함 |

## 판정표 틀

한 행에 번호 하나를 작성합니다. 번호는 점검표의 번호와 글자가 같아야 합니다.

| 번호 | 판정 | 놓친 곳 |
|---|---|---|
| B1-01 | 지킴 | - |
| B2-03 | 놓침 | 3문단 "한 발씩 진행합니다" |
| B2-T05 | 해당 없음 | 표가 없는 산출물 |

- 판정 칸은 지킴, 놓침, 해당 없음 가운데 하나로 시작합니다("놓침 2건"처럼 뒤에 덧붙이는 것은 허용).
- 놓침은 고친 뒤 다시 대조해 판정을 지킴으로 바꾸고, 놓친 곳 칸에 고친 내용을 남깁니다.
- 판정표는 표 하나로 모아도 되고 규칙 그룹별로 나눠도 됩니다. 누락 검사는 문서 안의 모든 표를 읽습니다.
- 표 안의 번호 칸 앞뒤에 `**`나 공백이 있어도 인식됩니다.
