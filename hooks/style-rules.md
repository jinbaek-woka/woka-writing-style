# 한국어 문서 문체 규칙 (woka-writing-style)

Woka 구성원의 Claude Code에 공통 적용되는 한국어 문서 문체 기준이다. 문서 산출물의 한국어 본문(헤딩·표 셀·콜아웃·불릿 포함)에 적용한다.

## 적용 범위

- 적용: 보고서·제안서·기획안·이메일·노션 페이지·강의자료·발표자료·공지문 등 업무 문서 산출물의 한국어 본문
- 미적용: 일상 대화·질문 답변·진행 상황 보고, 코드·주석·로그, 사용자 원문 인용, 사용자가 "구어체로"·"편하게 써줘"라고 지시한 경우

## 규칙 1 — 감성과잉 차단

- 호명·권유("여러분", "함께 알아봅시다") 금지
- 격려·감탄("도전해보세요", "성장의 기회", "이제 시작입니다") 금지
- 의미 부풀리기("효과적으로", "성공적으로", "완벽하게", "강력한") 금지. 단 "극대화"는 한자어 격식 표현으로 허용
- 문서 마무리는 희망·격려 멘트 없이 다음 행동 한 줄로 종결

## 규칙 2 — 종결 문체 구분

- 줄글(서술 문단): 존댓말(~습니다/~합니다)
- 개괄식(불릿·표 셀·슬라이드 정리): 개조식 — 명사 종결·조사 생략·'및' 연결 (예: "일정 확정 후 전체 공유 예정")
- "~예요·~죠·~거든요" 구어 종결과 반말 금지
- 한 덩어리(같은 문단·같은 표) 안에서 종결 문체 혼용 금지

## 규칙 3 — 구어 비유 동사 금지

아래 비유 동사가 본문에 들어가면 격식 대체어로 교체한다. 표에 없는 새 비유도 만들지 않는다.

| 구어 표현 | 격식 대체어 |
|---|---|
| 굴리다 | 적용·진행·운영 |
| 돌리다 | 진행·한 차례 진행·완주 |
| 못박다 | 고정·한정·특정·지정 |
| 손을 대다 | 참여·기여 |
| 한 발씩 | 부분적으로·각자 일정 부분씩 |
| 들고 가다 | 가지고 가다·보여주다 |
| 잡아두다 | 정리·확인 |
| 돌아가다(작동) | 동작·작동 |
| 거들다 | 참여·보조 |
| 박다·박혀 있다 | 넣다·삽입·담다·반영 |
| 꺼내 쓰다 | 불러오다·사용·자동 적용 |
| 굳히다(등록) | 등록·저장 |
| 쌓아두다(저장) | 등록해두다·저장해두다 |
| 닿아 있다(관련) | 관련된·연관된 |

## 규칙 4 — 표식 라벨 금지

"한 줄 요약:", "정리하면 —", "결론부터 —", "TL;DR" 같은 라벨+콜론·줄표 머리말을 쓰지 않고 내용을 곧바로 쓴다.

## 출력 직전 셀프체크 (강제)

문서 본문을 출력하기 전에 규칙 1~4를 한 번 훑고 위반 표현을 교체한 뒤 출력한다. 표 셀·콜아웃이라고 구어체를 허용하지 않는다.

## 자동 검수 절차

1. 분량 있는 한국어 문서(2문단 이상)는 완성 전에 `humanizer` 스킬(격식 모드)로 AI 티를 제거하고, 다듬어진 최종본만 제시한다.
2. 노션·이메일 등 외부에 게시·발송되는 문서는 "완료" 보고 전에 `korean-spell-check` 스킬로 맞춤법을 검수하고, 진짜 오류만 수정해 반영한다.
3. 기밀성 높은 문서는 맞춤법 검수를 생략한다(검수 텍스트가 외부 맞춤법 검사기로 전송되기 때문).
